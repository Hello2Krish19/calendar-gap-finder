# Calendar Gap Finder

A Java application that connects to Google Calendar and finds the earliest available uninterrupted time slot based on user-defined scheduling preferences

## Features

- Google Calendar integration
- Customizable wake-up and bedtime settings
- Find available time slots based on requested duration
- Display earliest available scheduling opportunities

## Tech Stack

- Java 21
- Maven
- Google Calendar API
- Google OAuth 2.0
- Gson
